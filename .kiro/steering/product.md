# Product Overview

## Jazz Portfolio

A jazz-themed, multilingual portfolio website with an integrated admin CMS and persistent background music player.

### Core Features

- **Multilingual Support**: English, Vietnamese, and Japanese localization with flag-based language switching
- **Jazz Theme**: Dark smoky aesthetic with brass/gold accents throughout
- **Background Music Player**: Persistent audio player with playlist support, maintains playback across page navigation
- **Portfolio Sections**: Hero, About, Experience, Skills, and Contact sections
- **Admin CMS**: Full content management system for profile, categories, music tracks, and settings
- **Dynamic Categories**: Flexible category system supporting Skills, Experience, Education, and custom types
- **Smooth Animations**: Scroll-based reveals, parallax effects, and page transitions using Framer Motion
- **Media Management**: S3-based storage with CloudFront CDN delivery
- **Responsive Design**: Mobile-first approach across all breakpoints

### Target Audience

Personal portfolio for showcasing professional experience, skills, and creative work with a distinctive jazz aesthetic.

### Out of Scope (v1)

- Blog/Posts functionality
- Comments system
- Multi-admin or role-based access
- Contact form with email integration
- Custom domain (using default AWS URLs)
